# QuizRx — Calcium/Bone Extraction Quiz API

Integration reference for the pre-authored ("extraction") Calcium/Bone quiz.
Status: **live on prod** (cognitive `v12.7.0`, backend `v11.5.0`).

---

## Overview

A new quiz type for Calcium/Bone, built from pre-authored content (no LLM):
the user picks a topic (chain) from a dropdown, gets a multiple-choice question,
answers it, sees an explanation, and we capture per-attempt feedback.

Questions are deterministic and fast — they are assembled on the cognitive
service from authored "decision points," not generated by an LLM.

## Architecture

```
Browser (Next.js)
   │  GraphQL (Apollo) + Firebase auth
   ▼
NestJS backend-api   ── extraction module: proxy only
   │  REST (server-to-server, no CORS)
   ▼
Cognitive service (FastAPI)  ── assembles the question, stores feedback (Mongo, keyed by dp_id)
```

The frontend talks **only** to GraphQL. The REST layer is internal.

## GraphQL API (what the frontend calls)

**Endpoint**
- Prod:  `https://quizrx-platform-backend-356295304767.us-central1.run.app/graphql`
- Local: `http://localhost:3001/graphql`
- Auth:  `Authorization: Bearer <firebaseIdToken>` (same as all other operations)

### Query — `getExtractionQuestion`

| Arg | Type | Notes |
|---|---|---|
| `chainId` | `String!` | one of the 9 chains (see table) |
| `dpId` | `String` | optional; omit for a random question, pass to re-fetch a specific one |

Returns `ExtractionQuestionResponse`:
```graphql
type ExtractionQuestionResponse {
  data: JSON          # full question payload (see "data shape")
  statusCode: Int!
  message: String!
  error: String
}
```

### Mutation — `submitQuestionFeedback`

```graphql
input QuestionFeedbackInput {
  chainId: String!
  dpId: String!
  isCorrect: Boolean!
  shownTrapIds: [String!]
  selectedTrapId: String        # null if the user picked the correct option
  selectedOptionLabel: String
  selectedOptionText: String
  rating: String                # "up" | "down"
  freeText: String
  sessionId: String
}

type QuestionFeedbackResult {
  feedbackId: String
  statusCode: Int!
  message: String!
  error: String
}
```
`userId` is injected server-side from the token — the client must NOT send it.

## `data` payload shape (from `getExtractionQuestion`)

```jsonc
{
  "question": {
    "question": "…stem…",
    "choices": ["…", "…", "…"],          // render in order; 3–5 options
    "answer": "…correct option text…",   // for grading
    "option_trap_ids": ["T2", null, "T1"], // 1:1 with choices; correct = null
    "dp_id": "CAL-BONE-01-DP-08",
    "concept_target": "CAL-BONE-01",
    "topic": "calcium-bone",
    "sub_topic": "…clinical phase…"
  },
  "part2_data": {
    "explanation": "…teaching explanation, show after answering…",
    "answer": "…correct option text…"
  },
  "concept_target": "CAL-BONE-01"
}
```

## Mapping an attempt → feedback (frontend)

```js
// i = index of the option the user picked
{
  chainId: data.concept_target,
  dpId: data.question.dp_id,
  isCorrect: choices[i] === data.question.answer,
  shownTrapIds: data.question.option_trap_ids.filter(Boolean),
  selectedTrapId: data.question.option_trap_ids[i],   // null if correct
  selectedOptionLabel: ["A","B","C","D","E"][i],
  selectedOptionText: choices[i],
  rating: "up" | "down" | null,
  freeText: "...",        // optional
  sessionId: "<session>"  // optional
}
```

## Chains (dropdown options)

| chainId | label |
|---|---|
| CAL-BONE-01 | Calcium & Bone Physiology |
| CAL-BONE-02 | Rickets & Osteomalacia |
| CAL-BONE-03 | Osteoporosis |
| CAL-BONE-04 | Paget's Disease of Bone |
| CAL-BONE-05 | Osteogenesis Imperfecta |
| CAL-HYP-01 | Hypercalcaemia (selected causes) |
| CAL-HYPO-01 | Hypocalcaemia |
| CAL-MG-01 | Hypomagnesaemia |
| CAL-PTH-01 | Primary Hyperparathyroidism |

Coverage: 9 chains, 234 decision points, 741 distractors. Options are capped at
5 total (1 correct + up to 4 distractors); short decision points stay 3–4 options.

## Internal REST (backend → cognitive; not called by the frontend)

Base (prod): `https://quizrx-cognitive-service-356295304767.us-central1.run.app`

| Method | Path |
|---|---|
| GET | `/api/v1/endocrinology/extraction-question/?chain_id={id}&dp_id={optional}` |
| POST | `/api/v1/endocrinology/question-feedback/` |

The GraphQL `data` field is the GET's `data.questions` passed through. The
mutation maps camelCase → snake_case and adds `user_id`. Feedback is persisted
in MongoDB keyed by `dp_id` (collection `quizrx-question-feedback`).

## Notes / scope

- Calcium/Bone only for now; all other quizzes are unchanged. Routing is gated on
  a loaded extraction file + the `EXTRACTION_ENABLED` flag (cognitive).
- Unknown/unsupported chains return a 404 (mapped to a GraphQL `NotFound` error).
- `data` is passed through as JSON to stay decoupled from cognitive-side shape
  changes; a fully-typed GraphQL object can be added later if preferred.
